## Как запустить:
make run

## Пояснения
1. По ТЗ не требуется id для команды, но я счёл логичным делать связи по id для стабильности 
и гибкости работы с именем команд.
2. Слой контроллера может показаться лишним в реализации ввиду валидации на уровне транспорта, 
но я решил все-таки реализовать его для возможности переноса на другой транспорт, например, gRPC.
3. .env запушен для упрощения запуска на Вашей стороне.
4. Структура для статистики может выглядеть чересчур сложной для одной ручки, но сделана для масштабируемости.
5. Знаю про тестовое окружение - не успеваю разнести.
